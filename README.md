# Photangralenphie Tap

## How do I install these formulae?

`brew install photangralenphie/tap/<formula>`

Or `brew tap photangralenphie/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "photangralenphie/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
